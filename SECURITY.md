# Trust boundary

Run this factory as a trusted local operator. The viewer binds to loopback and offers read-only access to the run artifacts. It is not an authenticated hosted service.

Briefs become structured proposals. The Codex workers run with a private configuration home, disabled tools and a read-only sandbox. The runner validates timing, dimensions, registered asset references and CTA before a trusted compiler escapes text into known HyperFrames scenes. It does not execute model-authored HTML or JavaScript.

Asset registration, source dependencies, browser rendering and media codecs remain trusted host operations. Hash checks bind registered bytes; they do not make an actively malicious media file safe. Do not expose this runner as an upload service or register arbitrary SVG, font, video or other files from strangers. This repository does not inherit Software Factory's rootless Workcell execution isolation.

Credentials live in ignored `.runtime/provider/` or the provider's supported secret store. Do not put them in briefs, receipts, source assets or commits. The readonly viewer can expose your local run text and media to any local client that can reach its port.

The dependency override pins Undici 7.30.2 to address advisories in the renderer's transitive version. See the [upstream security advisory](https://github.com/nodejs/undici/security/advisories/GHSA-mqg3-3v4r-cm32). Full renders and the dependency audit were rerun with the override.

Report security concerns privately to the repository maintainers. Do not include account tokens or private source media in a public issue.
